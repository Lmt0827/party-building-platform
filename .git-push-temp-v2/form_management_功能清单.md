# 表单管理功能清单

## 一、功能定位

在系统管理下维护平台业务表单，支持表单基础信息维护、字段结构配置、版本历史查看及表单预览。

## 二、功能模块

### 1. 表单列表

- 以表格形式展示所有表单。

- 列表字段：表单名称、表单类型、版本号、创建日期、创建人、状态、操作。

- 状态展示：启用（绿色）、停用（橙色）。

- 分页展示：每页 10 条，支持翻页。

### 2. 搜索与筛选

- 按表单名称进行关键字搜索。

- 按表单类型筛选：全部类型、新增、发布。

### 3. 编辑表单

点击「编辑」打开表单编辑弹窗，包含以下 Tab：

#### 3.1 基础信息

- 表单名称（必填）。

- 表单类型：仅支持「新增」和「发布」两种类型。

- 状态：启用 / 停用。

#### 3.2 表单设计器（仅「新增」类型表单显示）

- 展示当前表单已配置的字段卡片。

- 支持字段卡片上下拖拽排序。

- 支持修改字段显示名称。

- 支持设置字段是否必填。

- 支持设置字段是否隐藏。

- 支持删除字段。

- 不提供新增字段组件入口。

#### 3.3 版本管理

- 展示表单历史版本列表。

- 列表字段：版本号、创建时间、创建人、备注。

- 仅支持查看，不提供「新增版本」操作。

### 4. 表单预览

- 点击「预览」打开表单预览抽屉。

- 顶部展示表单基本信息：表单名称、表单类型、当前版本、状态、创建日期、创建人。

- 中部按字段类型渲染只读表单控件，支持展示必填标记和隐藏字段标识。

- 底部展示版本历史列表。

### 5. 删除表单

- 点击「删除」弹出确认框。

- 确认后从列表移除该表单。

## 三、业务规则

1. 表单类型只有两种：「新增」和「发布」。
2. 所有表单均支持编辑基础信息和查看版本历史。
3. 只有「新增」类型表单才会显示「表单设计器」Tab，支持字段结构维护。
4. 「发布」类型表单编辑时仅可维护基础信息和查看版本历史。
5. 表单设计器不提供新增字段入口，仅对已有字段进行排序、编辑、隐藏、删除。
6. 版本管理为只读，不可新增版本。

## 四、页面结构

- 页面路径：`form_management.html`

- 菜单入口：系统管理 → 表单管理
